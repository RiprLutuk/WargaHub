# Changelog

Semua perubahan penting WargaHub dicatat di file ini. Format mengikuti
[Keep a Changelog](https://keepachangelog.com/id-ID/1.1.0/) dan versi release
mengikuti [Semantic Versioning](https://semver.org/lang/id/).

## [Unreleased]

### Added

- Fondasi monorepo Bun dengan Vue PWA, Fastify REST API, dan shared contracts.
- Alur MVP organisasi, warga/rumah, pengumuman, tagihan/pembayaran, keuangan,
  pengaduan, kegiatan, ronda, dokumen, notifikasi, dashboard, RBAC, dan audit.
- Reference deployment Docker Compose, Caddy, backup/restore, dan dokumentasi
  self-hosting.

### Security

- Opaque session, Argon2id, CSRF validation, organization scoping, private file
  authorization, rate limiting, audit log, dan sanitized public projections.
