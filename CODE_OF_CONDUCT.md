# Kode Etik Komunitas

WargaHub dibangun untuk lingkungan yang inklusif. Peserta wajib menghormati waktu, kapasitas, identitas, privasi, dan kondisi fisik maupun mental orang lain.

Perilaku merendahkan, intimidasi, doxing, diskriminasi, pelecehan, atau penggunaan data proyek untuk mempermalukan warga tidak dapat diterima. Maintainer dapat menghapus konten, menolak kontribusi, atau membatasi partisipasi untuk menjaga komunitas yang aman.

Laporkan pelanggaran secara privat kepada maintainer proyek. Laporan akan ditangani secara terbatas dan proporsional.
